计算下列不定积分.（1）$\int\cos^{3}x\,\mathrm{d}x$；（2）$\int\sin^{3}x\,\mathrm{d}x$；（3）$\int\sec x\,\mathrm{d}x$；（4）$\int\sec^{3}x\,\mathrm{d}x$；（5）$\int\frac{1}{a^{2}-x^{2}}\,\mathrm{d}x\ (a\neq 0)$；（6）$\int\frac{1}{x^{2}-a^{2}}\,\mathrm{d}x\ (a\neq 0)$；（7）$\int\frac{1}{a^{2}+x^{2}}\,\mathrm{d}x\ (a\neq 0)$；（8）$\int\frac{1}{a^{2}+(x+b)^{2}}\,\mathrm{d}x\ (a\neq 0)$；（9）$\int\frac{1}{a^{2}-(x+b)^{2}}\,\mathrm{d}x\ (a>0)$；（10）$\int\frac{1}{(x+b)^{2}-a^{2}}\,\mathrm{d}x\ (a>0)$；（11）$\int\frac{1}{\sqrt{x^{2}-a^{2}}}\,\mathrm{d}x\ (a>0)$；（12）$\int\frac{1}{\sqrt{a^{2}-x^{2}}}\,\mathrm{d}x\ (a>0)$；（13）$\int\frac{1}{\sqrt{x^{2}+a^{2}}}\,\mathrm{d}x\ (a>0)$；（14）$\int\csc^{3}x\,\mathrm{d}x$；（15）$\int\tan^{2}x\,\mathrm{d}x$；（16）$\int\tan^{3}x\,\mathrm{d}x$；（17）$\int\tan^{4}x\,\mathrm{d}x$；（18）$\int\cot^{3}x\,\mathrm{d}x$；（19）$\int\frac{\cos x}{1+\sin x}\,\mathrm{d}x$；（20）$\int\frac{1}{a^{2}\sin^{2}x+b^{2}\cos^{2}x}\,\mathrm{d}x$；（21）$\int\frac{1}{\sin 2x}\,\mathrm{d}x$；（22）$\int\frac{1}{\cos 2x}\,\mathrm{d}x$；（23）$\int\frac{1}{a+b\cos x}\,\mathrm{d}x\ (a>0,b>0)$；（24）$\int\frac{1}{a+b\sin x}\,\mathrm{d}x\ (a>0,b>0)$.
(1) 方法一 $\int \cos^3 x\mathrm{d}x = \int (1-\sin^2 x)\mathrm{d}(\sin x) = \sin x - \frac{1}{3}\sin^3 x + C.$ 方法二 $\int \cos^3 x\mathrm{d}x = \int \frac{3\cos x + \cos 3x}{4}\mathrm{d}x = \frac{3}{4}\sin x + \frac{1}{12}\sin 3x + C.$ (2) 方法一 $\int \sin^3 x\mathrm{d}x = -\int (1-\cos^2 x)\mathrm{d}(\cos x) = -\cos x + \frac{1}{3}\cos^3 x + C.$ 方法二 $\int \sin^3 x\mathrm{d}x = \int \frac{3\sin x - \sin 3x}{4}\mathrm{d}x = -\frac{3}{4}\cos x + \frac{1}{12}\cos 3x + C.$ (3) 方法一 $\int \sec x\mathrm{d}x = \int \frac{\sec x(\sec x + \tan x)}{\sec x + \tan x}\mathrm{d}x = \int \frac{\mathrm{d}(\sec x + \tan x)}{\sec x + \tan x} = \ln \mid \sec x + \tan x \mid + C.$ 方法二 $\int \sec x\mathrm{d}x = \int \frac{\mathrm{d}x}{\cos x} = \int \frac{\mathrm{d}\left(x + \frac{\pi}{2}\right)}{\sin \left(x + \frac{\pi}{2}\right)} = \int \frac{\mathrm{d}\left(x + \frac{\pi}{2}\right)}{2\sin \left(\frac{x}{2} + \frac{\pi}{4}\right)\cos \left(\frac{x}{2} + \frac{\pi}{4}\right)}$ $$= \int \frac{\sec^2 \left(\frac{x}{2} + \frac{\pi}{4}\right)\mathrm{d}\left(\frac{x}{2} + \frac{\pi}{4}\right)}{\tan \left(\frac{x}{2} + \frac{\pi}{4}\right)} = \ln \left| \tan \left(\frac{x}{2} + \frac{\pi}{4}\right) \right| + C.$$ (4) $\int \sec^3 x\mathrm{d}x = \int \sec x\mathrm{d}(\tan x) = \sec x\tan x - \int \tan^2 x\sec x\mathrm{d}x$ $$= \sec x\tan x - \int (\sec^3 x - \sec x)\mathrm{d}x = \sec x\tan x - \int \sec^3 x\mathrm{d}x + \int \sec x\mathrm{d}x,$$ 又由(3)，得 $$\int \sec^3 x\mathrm{d}x = \frac{1}{2}\left[ \sec x\tan x + \ln \left| \tan \left(\frac{x}{2} + \frac{\pi}{4}\right) \right| \right] + C.$$ (5) $\int \frac{1}{a^2 - x^2}\mathrm{d}x = \int \frac{1}{2a}\left( \frac{1}{a+x} + \frac{1}{a-x} \right)\mathrm{d}x = \frac{1}{2a}(\ln \mid a+x \mid - \ln \mid a-x \mid) + C$ $$= \frac{1}{2a}\ln \left| \frac{a+x}{a-x} \right| + C.$$ (6) $\int \frac{1}{x^2 - a^2}\mathrm{d}x = -\frac{1}{2a}\int \left( \frac{1}{a+x} + \frac{1}{a-x} \right)\mathrm{d}x \xlongequal{\text{由(5)}} -\frac{1}{2a}\ln \left| \frac{a+x}{a-x} \right| + C.$ (7) $\int \frac{1}{a^2 + x^2}\mathrm{d}x = \int \frac{1}{a^2} \cdot \frac{1}{1 + \left(\frac{x}{a}\right)^2}\mathrm{d}x = \frac{1}{a}\int \frac{1}{1 + \left(\frac{x}{a}\right)^2}\mathrm{d}\left(\frac{x}{a}\right) = \frac{1}{a}\arctan \frac{x}{a} + C.$ (8) $\int \frac{1}{a^2 + (x+b)^2}\mathrm{d}x = \int \frac{1}{a^2 + (x+b)^2}\mathrm{d}(x+b) \xlongequal{\text{由(7)}} \frac{1}{a}\arctan \frac{x+b}{a} + C.$ (9) $\int \frac{1}{a^2 - (x+b)^2}\mathrm{d}x = \int \frac{1}{a^2 - (x+b)^2}\mathrm{d}(x+b)$ $$\xlongequal{\text{由(5)}} \frac{1}{2a}\ln \left| \frac{a + (x+b)}{a - (x+b)} \right| + C = \frac{1}{2a}\ln \left| \frac{x + a + b}{-x + a - b} \right| + C.$$ (10) $\int \frac{1}{(x+b)^2 - a^2}\mathrm{d}x = -\int \frac{1}{a^2 - (x+b)^2}\mathrm{d}x \xlongequal{\text{由(9)}} -\frac{1}{2a}\ln \left| \frac{x + a + b}{-x + a - b} \right| + C.$ (11) 设 $x = a\sec t$，有 $\mathrm{d}x = a\sec t\tan t\,\mathrm{d}t$. 当 $0 < t < \frac{\pi}{2}$ 时，$x = a\sec t > 0$，且存在反函数. $$\int \frac{\mathrm{d}x}{\sqrt{x^2 - a^2}} = \int \frac{a\sec t\tan t}{a\tan t}\mathrm{d}t = \int \sec t\,\mathrm{d}t = \ln(\sec t + \tan t) + C_1 = \ln(x + \sqrt{x^2 - a^2}) + C.$$ 当 $\frac{\pi}{2} < t < \pi$ 时，$x = a\sec t < 0$，且存在反函数. $$\int \frac{\mathrm{d}x}{\sqrt{x^2 - a^2}} = -\int \sec t\,\mathrm{d}t = -\ln(-\sec t - \tan t) + C_2$$ $$= -\ln(-x + \sqrt{x^2 - a^2}) + C_3 = \ln(-x - \sqrt{x^2 - a^2}) + C.$$ 综上，$\int \frac{\mathrm{d}x}{\sqrt{x^2 - a^2}} = \ln \mid x + \sqrt{x^2 - a^2} \mid + C.$ (12) $\int \frac{1}{\sqrt{a^2 - x^2}}\mathrm{d}x = \int \frac{1}{a} \cdot \frac{\mathrm{d}x}{\sqrt{1 - \left(\frac{x}{a}\right)^2}} = \int \frac{\mathrm{d}\left(\frac{x}{a}\right)}{\sqrt{1 - \left(\frac{x}{a}\right)^2}} = \arcsin \frac{x}{a} + C.$ (13) 设 $x = a\tan t$，则 $\mathrm{d}x = a\sec^2 t\,\mathrm{d}t$，当 $-\frac{\pi}{2} < t < \frac{\pi}{2}$ 时，$x = a\tan t$ 存在反函数. 所以 $$\int \frac{\mathrm{d}x}{\sqrt{x^2 + a^2}} = \int \frac{a\sec^2 t\,\mathrm{d}t}{a\sqrt{\tan^2 t + 1}} = \int \frac{\sec^2 t}{\sec t}\mathrm{d}t = \int \sec t\,\mathrm{d}t = \ln \mid \sec t + \tan t \mid + C_1.$$ 由 $\tan t = \frac{x}{a}$ 得 $\sec t = \frac{\sqrt{a^2 + x^2}}{a}$，所以 $$\int \frac{\mathrm{d}x}{\sqrt{x^2 + a^2}} = \ln \mid \sec t + \tan t \mid + C_1 = \ln \left( \frac{\sqrt{x^2 + a^2}}{a} + \frac{x}{a} \right) + C_1$$ $$= \ln(\sqrt{x^2 + a^2} + x) + C.$$ (14) $\int \csc^3 x\mathrm{d}x = \int \csc^2 x\csc x\mathrm{d}x = -\int \csc x\mathrm{d}(\cot x)$ $$= -\csc x\cot x + \int \cot x\mathrm{d}(\csc x) = -\csc x\cot x - \int \cot^2 x\csc x\mathrm{d}x$$ $$= -\csc x\cot x - \int \csc x(\csc^2 x - 1)\mathrm{d}x = -\csc x\cot x - \int \csc^3 x\mathrm{d}x + \int \csc x\mathrm{d}x,$$ $$\int \csc x\mathrm{d}x = \int \frac{\csc x(\csc x - \cot x)}{\csc x - \cot x}\mathrm{d}x = \int \frac{\mathrm{d}(\csc x - \cot x)}{\csc x - \cot x} = \ln \mid \csc x - \cot x \mid + C_1,$$ 故 $$\int \csc^3 x\mathrm{d}x = \frac{1}{2}(-\csc x\cot x + \ln \mid \csc x - \cot x \mid + C_1) = -\frac{1}{2}\csc x\cot x + \frac{1}{2}\ln \mid \csc x - \cot x \mid + C.$$ (15) $\int \tan^2 x\mathrm{d}x = \int \frac{\sin^2 x}{\cos^2 x}\mathrm{d}x = \int \frac{1 - \cos^2 x}{\cos^2 x}\mathrm{d}x = \int \sec^2 x\mathrm{d}x - \int 1\mathrm{d}x = \tan x - x + C.$ (16) $\int \tan^3 x\mathrm{d}x = \int \tan x(\sec^2 x - 1)\mathrm{d}x$ $$= \int \tan x\mathrm{d}(\tan x) - \int \tan x\mathrm{d}x = \frac{1}{2}\tan^2 x + \ln \mid \cos x \mid + C.$$ 【注】由上式可知 $n$ 次方的递推公式，即 $$\int \tan^n x\mathrm{d}x = \int \tan^{n-2} x(\sec^2 x - 1)\mathrm{d}x = \int \tan^{n-2} x\mathrm{d}(\tan x) - \int \tan^{n-2} x\mathrm{d}x = \frac{\tan^{n-1} x}{n-1} - \int \tan^{n-2} x\mathrm{d}x.$$ (17) $\int \tan^4 x\mathrm{d}x \xlongequal{\text{由(16)的注}} \frac{\tan^3 x}{3} - \int \tan^2 x\mathrm{d}x \xlongequal{\text{由(15)}} \frac{\tan^3 x}{3} - \tan x + x + C.$ (18) $\int \cot^3 x\mathrm{d}x = \int \frac{\cos^3 x}{\sin^3 x}\mathrm{d}x = \int \frac{1 - \sin^2 x}{\sin^3 x}\mathrm{d}(\sin x) = \int \frac{1}{\sin^3 x}\mathrm{d}(\sin x) - \int \frac{1}{\sin x}\mathrm{d}(\sin x) = -\frac{\csc^2 x}{2} + \ln \mid \csc x \mid + C.$ (19) 令 $\sin x = \frac{2t}{1+t^2}$，$\cos x = \frac{1-t^2}{1+t^2}$，其中 $t = \tan \frac{x}{2}$，则 $\mathrm{d}x = \frac{2\mathrm{d}t}{1+t^2}$，故 $$\int \frac{\cos x}{1 + \sin x}\mathrm{d}x = \int \frac{x}{2}} + C.$$ (20) $\int \frac{1}{a^2\sin^2 x + b^2\cos^2 x}\mathrm{d}x = \int \frac{\mathrm{d}x}{b^2\cos^2 x\left( \frac{a^2}{b^2}\tan^2 x + 1 \right)}$ $$= \frac{1}{b^2}\int 【解析】$\displaystyle\int_{-\infty}^{+\infty}\left|x\right|\mathrm{e}^{-x^2}\mathrm{d}x=2\int_{0}^{+\infty}x\mathrm{e}^{-x^2}\mathrm{d}x=-\int_{0}^{+\infty}\mathrm{e}^{-x^2}\mathrm{d}(-x^2)=-\mathrm{e}^{-x^2}\Big|_{0}^{+\infty}=1.$
最终答案1
23 选择题
设 $f(x)=\lim_{n \to \infty}\frac{1-x^{2n}}{1+x^{2n}}x$，且 $\int_{0}^{2}f(x)\,\mathrm{d}x=a$，则 $a$ 等于（　）.
(A)2(B)1(C)0(D)$-1$
【解析】由题可知， $$f(x)=\begin{cases}x, & |x|<1,\\0, & |x|=1,\\-x, & |x|>1,\end{cases}$$ 于是有 $$\int_{0}^{2}f(x)\mathrm{d}x=\int_{0}^{1}x\,\mathrm{d}x+\int_{1}^{2}(-x)\,\mathrm{d}x=-1.$$
最终答案(D)
24 填空题
$\int_{-1}^{1}\left(\frac{1}{1+2^{\frac{1}{x}}}\right)'\mathrm{d}x=$ ______.
【解析】 $$\text{原式}=\int_{-1}^{0^{-}}\left(\frac{1}{1+2^{\frac{1}{x}}}\right)'\mathrm{d}x+\int_{0^{+}}^{1}\left(\frac{1}{1+2^{\frac{1}{x}}}\right)'\mathrm{d}x$$ $$=\frac{1}{1+2^{\frac{1}{x}}}\bigg|_{-1}^{0^{-}}+\frac{1}{1+2^{\frac{1}{x}}}\bigg|_{0^{+}}^{1}$$ $$=1-\frac{2}{3}+\frac{1}{3}-0=\frac{2}{3}.$$
最终答案\frac{2}{3}
25 填空题
$\int_{-\frac{1}{2}}^{\frac{1}{2}}\frac{\left|x\right|\left(\arcsin x+\arccos x\right)}{\sqrt{1-x^{2}}}\,\mathrm{d}x=$ ______.
【解析】方法一　由于 $\arcsin x+\arccos x=\dfrac{\pi}{2}$，故 $$\text{原式}=\pi\int_{0}^{\frac{1}{2}}\frac{x}{\sqrt{1-x^2}}\mathrm{d}x=\pi\left(-\sqrt{1-x^2}\right)\Big|_{0}^{\frac{1}{2}}$$ $$=\pi\left(1-\frac{\sqrt{3}}{2}\right).$$ 方法二　原式$=\displaystyle\int_{-\frac{1}{2}}^{\frac{1}{2}}\frac{\left|x\right|\arccos x}{\sqrt{1-x^2}}\mathrm{d}x$ $$=\int_{-\frac{1}{2}}^{0}\frac{-x\arccos x}{\sqrt{1-x^2}}\mathrm{d}x+\int_{0}^{\frac{1}{2}}\frac{x\arccos x}{\sqrt{1-x^2}}\mathrm{d}x$$ $$=\sqrt{1-x^2}\arccos x\Big|_{-\frac{1}{2}}^{0}+\int_{-\frac{1}{2}}^{0}\mathrm{d}x-\sqrt{1-x^2}\arccos x\Big|_{0}^{\frac{1}{2}}-\int_{0}^{\frac{1}{2}}\mathrm{d}x$$ $$=\frac{\pi}{2}-\frac{\sqrt{3}}{2}\cdot\frac{2}{3}\pi-\frac{\sqrt{3}}{2}\cdot\frac{\pi}{3}+\frac{\pi}{2}$$ $$=\pi-\frac{\sqrt{3}}{2}\pi=\pi\left(1-\frac{\sqrt{3}}{2}\right).$$
最终答案\pi\left(1-\frac{\sqrt{3}}{2}\right)
26 填空题
积分 $I=\int_{1}^{\frac{3}{2}}\frac{(1-x)\arcsin(1-x)}{\sqrt{2x-x^{2}}}\,\mathrm{d}x=$ ______.
【解析】令 $u=1-x$，则 $$I=\int_{-\frac{1}{2}}^{0}\frac{u\arcsin u}{\sqrt{1-u^2}}\mathrm{d}u$$ $$=\int_{0}^{-\frac{1}{2}}\arcsin u\,\mathrm{d}(\sqrt{1-u^2})$$ $$=\sqrt{1-u^2}\arcsin u\Big|_{0}^{-\frac{1}{2}}-\int_{0}^{-\frac{1}{2}}\mathrm{d}u$$ $$=\frac{\sqrt{3}}{2}\cdot\left(-\frac{\pi}{6}\right)+\frac{1}{2}=\frac{1}{2}-\frac{\sqrt{3}}{12}\pi.$$
最终答案\frac{1}{2}-\frac{\sqrt{3}}{12}\pi
27 填空题
若 $f(x)=\frac{1}{1+x^{2}}+x^{3}\int_{0}^{1}f(x)\,\mathrm{d}x$，则 $f(x)=$ ______.
【解析】定积分$\displaystyle\int_{0}^{1}f(x)\mathrm{d}x$是一个常数，所以等式两端同时在 $[0,1]$ 上对 $x$ 进行积分得 $$\int_{0}^{1}f(x)\mathrm{d}x=\int_{0}^{1}\frac{1}{1+x^2}\mathrm{d}x+\int_{0}^{1}\left[x^3\int_{0}^{1}f(x)\mathrm{d}x\right]\mathrm{d}x,$$ 即 $$\int_{0}^{1}f(x)\mathrm{d}x=\arctan x\Big|_{0}^{1}+\int_{0}^{1}f(x)\,\mathrm{d}x\int_{0}^{1}x^3\,\mathrm{d}x$$ $$=\frac{\pi}{4}+\frac{1}{4}\int_{0}^{1}f(x)\,\mathrm{d}x,$$ 解得$\displaystyle\int_{0}^{1}f(x)\mathrm{d}x=\frac{\pi}{3}$，故 $f(x)=\dfrac{1}{1+x^2}+\dfrac{\pi}{3}x^3$.
最终答案\frac{1}{1+x^2}+\frac{\pi}{3}x^3
28 填空题
$\int_{-1}^{1}\left[x^{3}\cos x+\ln\left(x+\sqrt{x^{2}+1}\right)\right]\mathrm{d}x=$ ______.
【解析】方法一　显然，被积函数中第一项为奇函数. 判断被积函数中第二项也为奇函数，令 $f(x)=\ln(x+\sqrt{x^2+1})$，易知 $$f(-x)=\ln(\sqrt{x^2+1}-x)=\ln\frac{1}{\sqrt{x^2+1}+x}=-f(x),x\in\left[-1,1\right].$$ 由定积分性质可得，原式 $=0$. 方法二　由定积分性质，知第一项积分为 0. 利用分部积分法计算第二项积分. $$\text{原式}=x\ln\left(x+\sqrt{x^2+1}\right)\Big|_{-1}^{1}-\int_{-1}^{1}\frac{x}{\sqrt{x^2+1}}\mathrm{d}x$$ $$=\ln(1+\sqrt{2})+\ln(-1+\sqrt{2})-0=0.$$
最终答案0
29 选择题
设 $f(x)=\int_{0}^{x}\frac{\cos t}{1+\sin^{2}t}\,\mathrm{d}t$，则 $\int_{0}^{\frac{\pi}{2}}\frac{f'(x)}{1+f^{2}(x)}\,\mathrm{d}x=$（　）.
(A)$-\frac{\pi}{4}$(B)$-\arctan\frac{\pi}{4}$(C)$\frac{\pi}{4}$(D)$\arctan\frac{\pi}{4}$
【解析】先求出 $f(x)$ 的表达式，再由定积分算出结果. $$f(x)=\int_{0}^{x}\frac{\cos t}{1+\sin^2t}\mathrm{d}t=\int_{0}^{x}\frac{\mathrm{d}(\sin t)}{1+\sin^2t}=\arctan(\sin x).$$ $$\int_{0}^{\frac{\pi}{2}}\frac{f'(x)}{1+f^2(x)}\mathrm{d}x=\int_{0}^{\frac{\pi}{2}}\frac{\mathrm{d}\left[f(x)\right]}{1+f^2(x)}=\arctan f(x)\Big|_{0}^{\frac{\pi}{2}}$$ $$=\arctan f\left(\frac{\pi}{2}\right)-\arctan f(0)=\arctan\frac{\pi}{4}.$$
最终答案(D)
30 选择题
设 $\int_{1}^{+\infty}f(x)\,\mathrm{d}x$ 收敛，$f(x)=x^{3}\mathrm{e}^{-x^{2}}+\frac{1}{x(1+x)}\int_{1}^{+\infty}f(x)\,\mathrm{d}x$，则 $\int_{1}^{+\infty}f(x)\,\mathrm{d}x=$（　）.
(A)$\frac{1}{1-\ln 2}$(B)$\frac{1}{\ln 2}$(C)$\frac{\mathrm{e}}{1-\ln 2}$(D)$\frac{1}{(1-\ln 2)\mathrm{e}}$
【解析】$\quad I=\displaystyle\int_{1}^{+\infty}f(x)\,\mathrm{d}x=\int_{1}^{+\infty}x^3\mathrm{e}^{-x^2}\mathrm{d}x+\int_{1}^{+\infty}f(x)\,\mathrm{d}x\cdot\int_{1}^{+\infty}\frac{\mathrm{d}x}{x(1+x)},$ $$I=-\frac{1}{2}\int_{1}^{+\infty}x^2\,\mathrm{d}(\mathrm{e}^{-x^2})+I\cdot\int_{1}^{+\infty}\left(\frac{1}{x}-\frac{1}{1+x}\right)\mathrm{d}x$$ $$=-\frac{1}{2}x^2\mathrm{e}^{-x^2}\Big|_{1}^{+\infty}+\int_{1}^{+\infty}x\mathrm{e}^{-x^2}\,\mathrm{d}x+I\ln 2,$$ 故 $$(1-\ln 2)I=\frac{1}{2}\mathrm{e}^{-1}-\frac{1}{2}\mathrm{e}^{-x^2}\Big|_{1}^{+\infty}=\mathrm{e}^{-1},$$ 所以 $I=\dfrac{1}{(1-\ln 2)\mathrm{e}}$.

31 选择题
设 $\alpha(x)=\int_{0}^{x}tf(t)\,\mathrm{d}t$，$\beta(x)=\int_{0}^{x}xf(t)\,\mathrm{d}t$，$f(x)>0$，且 $f'(x)=o(x)\ (x\to 0^{+})$，则当 $x\to 0^{+}$ 时，$\alpha(x)$ 是 $\beta(x)$ 的（　）.
(A)高阶无穷小(B)低阶无穷小(C)等价无穷小(D)同阶但非等价无穷小
【解析】因 $$\lim_{x\to 0^{+}}\frac{\alpha(x)}{\beta(x)}=\lim_{x\to 0^{+}}\frac{\displaystyle\int_{0}^{x}tf(t)\,\mathrm{d}t}{\displaystyle x\int_{0}^{x}f(t)\,\mathrm{d}t}$$ $$=\lim_{x\to 0^{+}}\frac{xf(x)}{\displaystyle\int_{0}^{x}f(t)\,\mathrm{d}t+xf(x)}$$ $$=\lim_{x\to 0^{+}}\frac{f(x)+xf'(x)}{2f(x)+xf'(x)}=\frac{1}{2},$$ 故当 $x\to 0^{+}$ 时，$\alpha(x)$ 是 $\beta(x)$ 的同阶但非等价无穷小.
最终答案(D)
32 选择题
设函数 $f(x)$ 及其反函数 $f^{-1}(x)$ 都可导，且有 $\int_{2}^{f(x)}f^{-1}(t)\,\mathrm{d}t=\frac{1}{3}x^{\frac{3}{2}}-9$，则 $f(x)=$（　）.
(A)$\sqrt{x}-1$(B)$\sqrt{x}+1$(C)$2\sqrt{x}-1$(D)$2\sqrt{x}+1$
【解析】 $$\int_{2}^{f(x)}f^{-1}(t)\,\mathrm{d}t=\frac{1}{3}x^{\frac{3}{2}}-9,$$ 对上式两端求导，得 $$f^{-1}\left[f(x)\right]\cdot f'(x)=\frac{1}{2}x^{\frac{1}{2}},$$ $$xf'(x)=\frac{1}{2}x^{\frac{1}{2}},$$ $$f'(x)=\frac{1}{2}x^{-\frac{1}{2}},$$ 解得 $$f(x)=\sqrt{x}+C.$$ 当 $f(x)=2$ 时，有 $\dfrac{1}{3}x^{\frac{3}{2}}-9=0$，则 $x=9$，于是有 $C=-1$，故 $f(x)=\sqrt{x}-1$.
最终答案(A)
33 选择题
设 $f(x)$ 在 $(-\infty,+\infty)$ 上有连续的导数，则 $\lim_{a \to 0^{+}}\frac{1}{4a^{2}}\int_{-a}^{a}\left[f(t+a)-f(t-a)\right]\mathrm{d}t=$（　）.
(A)0(B)$f'(0)$(C)$\frac{1}{4}f'(0)$(D)不存在
【解析】 $$\lim_{a\to 0^{+}}\frac{1}{4a^2}\int_{-a}^{a}\left[f(t+a)-f(t-a)\right]\mathrm{d}t$$ $$=\lim_{a\to 0^{+}}\frac{1}{4a^2}\left[\int_{-a}^{a}f(t+a)\,\mathrm{d}t-\int_{-a}^{a}f(t-a)\,\mathrm{d}t\right]$$ $$=\lim_{a\to 0^{+}}\frac{1}{4a^2}\left[\int_{0}^{2a}f(t)\,\mathrm{d}t-\int_{-2a}^{0}f(t)\,\mathrm{d}t\right]$$ $$=\lim_{a\to 0^{+}}\frac{2f(2a)-2f(-2a)}{8a}$$ $$=\lim_{a\to 0^{+}}\frac{4f'(2a)+4f'(-2a)}{8}$$ $$=f'(0).$$
最终答案(B)
34 解答题
设 $f(x)=\int_{1}^{\sqrt{x}}\mathrm{e}^{-t^{2}}\,\mathrm{d}t$，求 $I=\int_{0}^{1}\frac{f(x)}{\sqrt{x}}\,\mathrm{d}x$.
【解析】方法一　将 $f(x)$ 代入积分 $I$ 中，得到二重积分， $$I=\int_{0}^{1}\frac{\displaystyle\int_{1}^{\sqrt{x}}\mathrm{e}^{-t^2}\,\mathrm{d}t}{\sqrt{x}}\,\mathrm{d}x$$ $$=\int_{0}^{1}\left(x^{-\frac{1}{2}}\int_{1}^{\sqrt{x}}\mathrm{e}^{-t^2}\,\mathrm{d}t\right)\mathrm{d}x$$ $$=-\int_{0}^{1}\left(x^{-\frac{1}{2}}\int_{\sqrt{x}}^{1}\mathrm{e}^{-t^2}\,\mathrm{d}t\right)\mathrm{d}x,$$ 积分区域如图所示，交换积分次序，得 【图】$t$ 轴（纵）与 $x$ 轴（横）坐标系中画出曲线 $x=t^2$，曲线过原点，标注点 $(1,1)$，由虚线分别连至两轴，曲线与 $t$ 轴及 $t=1$ 围成积分区域. $$I=-\int_{0}^{1}\mathrm{e}^{-t^2}\,\mathrm{d}t\int_{0}^{t^2}\frac{\mathrm{d}x}{\sqrt{x}}$$ $$=-2\int_{0}^{1}\mathrm{e}^{-t^2}\left(\sqrt{x}\Big|_{x=0}^{x=t^2}\right)\mathrm{d}t$$ $$=-2\int_{0}^{1}t\mathrm{e}^{-t^2}\,\mathrm{d}t=\mathrm{e}^{-t^2}\Big|_{0}^{1}=\mathrm{e}^{-1}-1.$$ 方法二　用分部积分法. $$I=2\int_{0}^{1}f(x)\,\mathrm{d}(\sqrt{x})$$ $$=2\sqrt{x}f(x)\Big|_{0}^{1}-2\int_{0}^{1}\sqrt{x}f'(x)\,\mathrm{d}x$$ $$=-2\int_{0}^{1}\sqrt{x}\mathrm{e}^{-x}\frac{1}{2\sqrt{x}}\mathrm{d}x=-\int_{0}^{1}\mathrm{e}^{-x}\mathrm{d}x=\mathrm{e}^{-x}\Big|_{0}^{1}=\mathrm{e}^{-1}-1.$$
35 填空题
$\int_{1}^{+\infty}\frac{\mathrm{d}x}{x\sqrt{x^{2}+2x-1}}=$ ______.
作变换 $t=\dfrac{1}{x}$，故 $$\text{原积分}=-\int_{1}^{0}\frac{\mathrm{d}t}{\sqrt{1+2t-t^{2}}}=\int_{0}^{1}\frac{\mathrm{d}t}{\sqrt{2-(1-t)^{2}}}=-\arcsin\frac{1-t}{\sqrt{2}}\Big|_{0}^{1}=\arcsin\frac{1}{\sqrt{2}}=\frac{\pi}{4}.$$
最终答案$\frac{\pi}{4}$
36 填空题
$\int_{0}^{+\infty}\left(\sqrt{x^{2}+1}-x\right)^{2}\mathrm{d}x=$ ______.
$$\int_{0}^{+\infty}\left(\sqrt{x^{2}+1}-x\right)^{2}\mathrm{d}x=\int_{0}^{+\infty}\frac{\mathrm{d}x}{\left(\sqrt{x^{2}+1}+x\right)^{2}}$$ $$\xlongequal{x=\tan t}\int_{0}^{\frac{\pi}{2}}\frac{\mathrm{d}t}{(1+\sin t)^{2}}\xlongequal{u=\tan\frac{t}{2}}\int_{0}^{1}\frac{\dfrac{2}{1+u^{2}}\mathrm{d}u}{\left(1+\dfrac{2u}{1+u^{2}}\right)^{2}}$$ $$=2\int_{0}^{1}\frac{1+u^{2}}{(1+u)^{4}}\mathrm{d}u=2\int_{0}^{1}\frac{(1+u)^{2}-2u}{(1+u)^{4}}\mathrm{d}u$$ $$=2\left[\int_{0}^{1}\frac{\mathrm{d}u}{(1+u)^{2}}-2\int_{0}^{1}\frac{u+1-1}{(1+u)^{4}}\mathrm{d}u\right]$$ $$=2\left\{\int_{0}^{1}\frac{\mathrm{d}u}{(1+u)^{2}}-2\int_{0}^{1}\left[\frac{1}{(1+u)^{3}}-\frac{1}{(1+u)^{4}}\right]\mathrm{d}u\right\}$$ $$=2\left\{-\frac{1}{1+u}\Big|_{0}^{1}-2\left[-\frac{1}{2(1+u)^{2}}\Big|_{0}^{1}+\frac{1}{3(1+u)^{3}}\Big|_{0}^{1}\right]\right\}$$ $$=\frac{2}{3}.$$
最终答案$\frac{2}{3}$
