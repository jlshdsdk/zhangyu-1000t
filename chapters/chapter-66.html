1 选择题
设 $X\sim B\left(1,\frac{1}{2}\right)$，$X_1,X_2,X_3$ 为来自总体 $X$ 的简单随机样本，$\overline{X}$ 为样本均值，则 $P\left\{\overline{X}>\frac{1}{3}\right\}=(\quad)$.
(A)$\frac{3}{8}$(B)$\frac{1}{2}$(C)$\frac{5}{8}$(D)$\frac{7}{8}$
因为 $X \sim B\left(1, \frac{1}{2}\right)$, $X_1, X_2, X_3$ 为来自总体 $X$ 的简单随机样本, 所以 $\sum_{i=1}^{3} X_i \sim B\left(3, \frac{1}{2}\right)$. 于是 $$P\left\{\overline{X} > \frac{1}{3}\right\} = P\left\{\sum_{i=1}^{3} X_i > 1\right\} = 1 - P\left\{\sum_{i=1}^{3} X_i = 0\right\} - P\left\{\sum_{i=1}^{3} X_i = 1\right\}$$ $$= 1 - C_3^0\left(\frac{1}{2}\right)^0\left(\frac{1}{2}\right)^3 - C_3^1\left(\frac{1}{2}\right)^1\left(\frac{1}{2}\right)^2 = \frac{1}{2}.$$ 应选 (B).
最终答案(B)
2 选择题
设随机变量 $X_1,X_2,X_3,X_4$ 相互独立且都服从标准正态分布 $N(0,1)$，已知 $Y=\frac{X_1^2+X_2^2}{X_3^2+X_4^2}$，对给定的 $\alpha\,(0<\alpha<1)$，数 $y_\alpha$ 满足 $P\{Y>y_\alpha\}=\alpha$，则有（　　）.
(A)$y_\alpha y_{1-\alpha}=1$(B)$y_\alpha y_{1-\frac{\alpha}{2}}=1$(C)$y_\alpha y_{1-\alpha}=\frac{1}{2}$(D)$y_\alpha y_{1-\frac{\alpha}{2}}=\frac{1}{2}$
依题意可知, $X_1^2 + X_2^2$ 与 $X_3^2 + X_4^2$ 相互独立且都服从自由度为 2 的 $\chi^2$ 分布, 因此 $Y = \frac{X_1^2 + X_2^2}{X_3^2 + X_4^2} = \dfrac{\dfrac{X_1^2 + X_2^2}{2}}{\dfrac{X_3^2 + X_4^2}{2}} \sim F(2,2)$. 因为 $P\{Y > y_α\} = α$, 即 $y_α = F_α(2,2)$, 又 $$1 - α = 1 - P\{Y > y_α\} = P\{Y \leqslant y_α\} = P\{Y < y_α\} = P\left\{\frac{1}{Y} > \frac{1}{y_α}\right\},$$ 而 $\dfrac{1}{Y} \sim F(2,2)$, 所以 $\dfrac{1}{y_α} = F_{1-α}(2,2)$, 又由 $y_α = F_α(2,2)$, 知 $y_{1-α} = F_{1-α}(2,2)$, 于是 $y_{1-α} = \dfrac{1}{y_α}$, 即 $y_α y_{1-α} = 1$. 故应选 (A).
最终答案(A)
3 选择题
设 $X_1,X_2,\cdots,X_n$ 是来自总体 $N(0,1)$ 的简单随机样本，记 $\overline{X}=\frac{1}{n}\sum\limits_{i=1}^{n}X_i$，$S^2=\frac{1}{n-1}\sum\limits_{i=1}^{n}(X_i-\overline{X})^2$，$T=(\overline{X}+1)(S^2+1)$，则 $E(T)$ 的值为（　　）.
(A)$0$(B)$1$(C)$2$(D)$4$
依题意可知 $E(\overline{X}) = 0$, $E(S^2) = 1$, 且 $\overline{X}, S^2$ 相互独立. 所以 $$E(T) = E[(\overline{X}+1)(S^2+1)] = E(\overline{X}+1)E(S^2+1) = 1 · (1+1) = 2.$$
最终答案(C)
4 选择题
设 $X_1,X_2$ 是取自正态总体 $X\sim N(1,1)$ 的简单随机样本，则 $\frac{X_1-1}{|1-X_2|}$ 服从（　　）.
(A)$N(1,1)$(B)$\chi^2(1)$(C)$t(1)$(D)$F(1,1)$
由 $t$ 分布形式可知 $$\frac{X_1 - 1}{\left|1 - X_2\right|} = \dfrac{\dfrac{X_1 - 1}{1}}{\sqrt{\left(\dfrac{X_2 - 1}{1}\right)^2 / 1}} \sim t(1).$$
最终答案(C)
5 选择题
设随机变量 $X\sim N(0,4)$，若 $X_1,X_2,\cdots,X_n\,(n>2)$ 是来自总体 $X$ 的简单随机样本，则（　　）.
(A)$\frac{1}{2n}\left(\sum\limits_{i=1}^{n}X_i\right)^2\sim\chi^2(1)$(B)$\frac{1}{16}\sum\limits_{i=1}^{n}X_i^2\sim\chi^2(n)$(C)$\sqrt{\frac{(n-1)X_{n}^{2}}{\sum\limits_{i=1}^{n-1}X_i^2}}\sim t(n-1)$(D)$\frac{(n-1)X_1^2}{\sum\limits_{i=2}^{n}X_i^2}\sim F(1,n-1)$
方法一　因为 $X \sim N(0,4)$, 所以 $\dfrac{1}{2}X \sim N(0,1)$, $\dfrac{1}{2}X_i \sim N(0,1)$ $(i = 1, 2, \cdots, n)$, 从而 $\dfrac{1}{2\sqrt{n}}\sum_{i=1}^{n} X_i \sim N(0,1)$. 于是, $$\left(\frac{1}{2\sqrt{n}}\sum_{i=1}^{n} X_i\right)^2 = \frac{1}{4n}\left(\sum_{i=1}^{n} X_i\right)^2 \sim \chi^2(1),$$ $$\sum_{i=1}^{n}\left(\frac{1}{2}X_i\right)^2 = \frac{1}{4}\sum_{i=1}^{n} X_i^2 \sim \chi^2(n),$$ $$\frac{\dfrac{1}{2}X_n}{\sqrt{\dfrac{\dfrac{1}{4}\sum_{i=1}^{n-1} X_i^2}{n-1}}} = \frac{\sqrt{n-1}X_n}{\sqrt{\sum_{i=1}^{n-1} X_i^2}} \sim t(n-1).$$ 因此, 选项 (A), (B), (C) 均不正确. 方法二　因为 $X \sim N(0,4)$, 所以 $\dfrac{1}{2}X \sim N(0,1)$, $\dfrac{1}{2}X_i \sim N(0,1)$ $(i = 1, 2, \cdots, n)$, 从而 $\left(\dfrac{1}{2}X_1\right)^2 = \dfrac{1}{4}X_1^2 \sim \chi^2(1)$, $\sum_{i=2}^{n}\left(\dfrac{1}{2}X_i\right)^2 = \dfrac{1}{4}\sum_{i=2}^{n} X_i^2 \sim \chi^2(n-1)$. 于是, $$\frac{(n-1)X_1^2}{\sum_{i=2}^{n} X_i^2} = \dfrac{\dfrac{1}{4}X_1^2}{\dfrac{\dfrac{1}{4}\sum_{i=2}^{n} X_i^2}{n-1}} \sim F(1, n-1).$$
最终答案(D)
6 选择题
已知随机变量 $X,Y$，且 $(X,Y)$ 的概率密度为 $f(x,y)=\frac{1}{4\pi}\mathrm{e}^{-\frac{x^2}{2}-\frac{(y-1)^2}{8}}$，则 $\frac{4X^2}{(Y-1)^2}$ 服从（　　）.
(A)$\chi^2(2)$(B)$t(1)$(C)$N(0,2^2)$(D)$F(1,1)$
由题意知, $f(x,y) = \dfrac{1}{2\pi · 1 · 2}\mathrm{e}^{-\frac{1}{2}\left[x^2 + \left(\frac{y-1}{2}\right)^2\right]}$, 故 $(X,Y) \sim N(0,1;1,2^2;0)$, 于是 $X \sim N(0,1)$, $Y \sim N(1,2^2)$, 且 $X, Y$ 相互独立, 则 $$X^2 \sim \chi^2(1), \quad \frac{(Y-1)^2}{2^2} \sim \chi^2(1),$$ 故 $\dfrac{4X^2}{(Y-1)^2} \sim F(1,1)$.
最终答案(D)
7 解答题
设 $X_1,X_2,\cdots,X_9$ 是来自正态总体 $X$ 的简单随机样本，记 $$Y_1=\frac{1}{6}(X_1+X_2+\cdots+X_6),$$ $$Y_2=\frac{1}{3}(X_7+X_8+X_9),$$ $$S^2=\frac{1}{2}\sum\limits_{i=7}^{9}(X_i-Y_2)^2,\,Z=\frac{\sqrt{2}(Y_1-Y_2)}{S},$$ 证明统计量 $Z$ 服从自由度为 2 的 $t$ 分布.
记 $\sigma^2 = D(X)$. 易见 $$E(Y_1) = E(Y_2), D(Y_1) = \frac{\sigma^2}{6}, D(Y_2) = \frac{\sigma^2}{3}.$$ 由于随机变量 $X_1, X_2, \cdots, X_9$ 独立同分布, 可见 $Y_1$ 和 $Y_2$ 独立, 且 $$E(Y_1 - Y_2) = 0, D(Y_1 - Y_2) = \frac{\sigma^2}{6} + \frac{\sigma^2}{3} = \frac{\sigma^2}{2},$$ 因此 $$U = \frac{Y_1 - Y_2}{σ/\sqrt{2}} \sim N(0,1).$$ 对于正态总体的样本方差 $S^2$, 随机变量 $$\chi^2 = \frac{2S^2}{σ^2}$$ 服从自由度为 2 的 $\chi^2$ 分布. 容易证明, $Y_1, Y_2, S^2$ 相互独立. 事实上, 对于任意实数 $u, v, w$, 有 $$P\{Y_1 \leqslant u, Y_2 \leqslant v, S^2 \leqslant w\}$$ $$= P\{Y_1 \leqslant u\}P\{Y_2 \leqslant v, S^2 \leqslant w\}$$ $$= P\{Y_1 \leqslant u\}P\{Y_2 \leqslant v\}P\{S^2 \leqslant w\},$$ 其中第一个等式成立, 因为 $X_1, X_2, \cdots, X_6$ 和 $X_7, X_8, X_9$ 相互独立; 第二个等式成立, 因为正态总体的样本均值和样本方差相互独立, 从而 $Y_1 - Y_2$ 和 $S^2$ 独立. 于是, 由服从 $t$ 分布的随机变量的典型模式, 知统计量 $$Z = \frac{\sqrt{2}(Y_1 - Y_2)}{S} = \dfrac{\dfrac{Y_1 - Y_2}{σ/\sqrt{2}}}{\sqrt{\dfrac{2S^2}{σ^2}\Big/ 2}} = \frac{U}{\sqrt{\chi^2/2}}$$ 服从自由度为 2 的 $t$ 分布.
